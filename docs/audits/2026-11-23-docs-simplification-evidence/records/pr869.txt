- **migration-guide:**
  - it says it covers 0.1.x to 0.2.0, and that some APIs shown were later removed;

  - the old default-scope block is deleted and the page links the live defaults (decision, C15);
  - the "scope was required before 0.2.0" claim, which was false even then, is fixed, along with the wrong signature block, `find_routes` (a plugin method, never an analyzer one) and the invalid rollback `pip install`.
- **api-redesign** (decision (b)): a note under the title says the page records the redesign's design, with current shapes in `docs/reference/tools.md`, `edges.md` and the python-explore skill; no sections were added. The outright-wrong examples are fixed:

  - relative `file` paths;

  - the TypeRef cache sentence;
  - a stale line reference and a private `~/.claude` cross-reference.
