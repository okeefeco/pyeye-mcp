- `re_exports` (`inspect`'s field and `expand(handle, "re_exports")`) now lists the spellings a `from x import *` re-exports, by the same rule `resolve` follows: the source's static `__all__`, else any name not starting with `_`. For example, `inspect("django.forms.forms.Form").re_exports` now includes `django.forms.Form`, where it was empty (#1010).
- The class graph behind `subclasses` follows a star import by that rule too, where it used to follow it for any name. A subclass whose base was reached through a star that doesn't export it (a name missing from the source's `__all__`, or an underscore name) is now found through Jedi instead of the AST, or not at all if Jedi can't resolve it either. On django, none of the 9,724 class bases changed (#1010).
