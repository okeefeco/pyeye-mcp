- A typed `NamedTuple` class now shows the constructor its fields generate, such as `Hexdigest(md5: str | None, sha256: str | None, blake2_256: str | None)`. It used to show `typing.NamedTuple`'s functional form, `(typename, fields, /)`. A subclass of a NamedTuple class, whose fields are inherited, shows no signature rather than a wrong one (#1126).
- An attribute or variable that can be `None` (`x: int | None`, `Optional[X]`, `= None`) no longer carries `"signature": "NoneType()"`, because `None` isn't callable. A variable that aliases a real function or class keeps its signature (#1126).
