- The stdio MCP server now exits promptly on SIGTERM, SIGINT and SIGHUP (CTRL_BREAK on Windows). It stops the Jedi worker and the file watchers, then exits 0, and a deadline ends the process even if a cleanup step hangs. Before, SIGTERM and SIGHUP were only logged, and SIGINT waited until the client next wrote to stdin, so only SIGKILL stopped a server whose client had gone (#1124).
- When the client closes stdin, the server now stops its file watchers before the interpreter exits, instead of from an `atexit` handler that runs too late on Windows, where a watcher's thread could keep the process alive (#1124).
