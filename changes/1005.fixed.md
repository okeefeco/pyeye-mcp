- On Windows, a file whose path can't be resolved strictly (access denied on a parent directory, a `WindowsApps` app-exec alias, an unusual name) is no longer refused as if it were in a restricted directory. Only a symlink loop still counts as restricted there; any other such path falls back to a normal resolve, which is still checked against the deny-list, so a credential store below the server's home stays refused. POSIX is unchanged (#1005).
