- A real package whose directory is named like a cache or build directory (`env`, `build`, `dist`, `venv`…) is scanned again, because it holds `__init__.py` or `__init__.pyi`. Before, every whole-tree scan dropped it by name, so `imported_by`, `subclasses`, the framework plugins and the module listing silently missed its modules (on Poetry, all of `poetry/utils/env/`), and the file watcher ignored edits to it. A virtual environment is now recognised by its `pyvenv.cfg` whatever it is called, and a namespace package with such a name is still skipped; the `subclasses` and `imported_by` ceilings say so. A top-level `build/` or `dist/` package is classified as project code (#1104).
