- `find_cli_commands` finds a command registered with a bare `@app.cli.command` (or `@bp.cli.command`), without parentheses, which it used to miss silently (#980).
- The plugin docs now say exactly what each tool covers: when a Flask route has no `urls`, when an error handler's `error_code` is `null`, which files `find_django_models` and `find_django_templates` read, and that `TEMPLATES` `DIRS` isn't. The troubleshooting guide's environment-variable examples now set the variables on the MCP client's server entry, as the guide itself says to, instead of with a shell `export` the server never sees.
