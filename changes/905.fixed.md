- `find_flask_routes` now reports routes declared with Flask 2.0's shortcut decorators: `@app.get(...)`, `.post`, `.put`, `.delete` and `.patch`, on an app or a blueprint. Each is a `route` record whose `methods` is the one method the shortcut names. A file that used only the shortcuts used to return a confident `[]`.
  - A shortcut counts only when its receiver is a name the same file binds to `Flask(...)` or `Blueprint(...)`, including an app factory's local `app`. So FastAPI's `@router.get(...)` and decorators such as `@cache.get("k")` are not reported.
  - A blueprint imported from another module isn't recognised for the shortcuts; `@bp.route(...)` on it is still found. (#905)
