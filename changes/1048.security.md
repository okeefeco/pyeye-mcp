- On Windows, a path a repository supplies is refused before anything looks it up when it is a network (UNC) or device path, or relative to a drive's current directory or root. Looking one up connects to its host over SMB, which can send the user's NTLM credentials there. This covers a `.pth` line in the project's environment, a declared path dependency in `pyproject.toml`, `[tool.pyright]` extra paths and build-backend layouts, and the `packages`, `namespaces`, `standalone.dirs` and `environment` entries of the project's own config files. A refused config entry is reported in `rejected_paths`. Paths the user or agent passes to a tool, and the user's global config, are not refused (#1048).
