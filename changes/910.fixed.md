- `find_flask_routes` now finds shortcut routes (`@bp.get(...)` and the others) on an app or blueprint imported from another module: `from .blueprints import bp`, an alias, a re-export through a package's `__init__`, or a module attribute such as `blueprints.bp`. The import is placed through pyeye's resolver, and the definition it lands on must itself be a `Flask(...)` or `Blueprint(...)` binding. So an imported FastAPI router or cache is still not reported. A receiver passed in as a function argument still can't be placed. (#910)
