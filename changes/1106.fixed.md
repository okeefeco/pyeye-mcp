- A name declared under `if TYPE_CHECKING:` and defined at runtime in the `else:` branch (Scrapy's `Spider.parse`) is now reported as the runtime definition. `resolve`, `inspect`, `expand(members)` and `outline` give its kind, signature, docstring and location; before, they showed the declaration as an attribute. A name bound only under the guard is unchanged (#1106).
- The same rule covers any runtime binding, not only a `def`. With `if TYPE_CHECKING: from .thing import A` and `else: A = object`, `A` now resolves to the runtime placeholder `A = object`, a `variable` in that module, instead of collapsing onto the imported class (#1106).
