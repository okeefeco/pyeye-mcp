- The unified metrics store (`~/.pyeye/metrics/active_sessions.json`) no longer grows without bound or tears. Every MCP call rewrites it, so as it grew, every call got slower. (#914)
  - Active sessions idle for longer than `pyeye.unified_metrics.STALE_SESSION_AGE` are closed and moved to `completed_sessions.jsonl` when the server starts. This includes sessions left behind by killed servers.
  - A process keeps one session across all its threads.
  - The store is written whole (a temporary file, then a replace), so a reader never sees a partial file.
  - An update that can't get the file lock is skipped instead of written unlocked, which could wipe other sessions.
  - The test suite no longer writes your real store.
- `PYEYE_METRICS_DIR` sets where the unified metrics are stored (default `~/.pyeye/metrics`). (#914)
