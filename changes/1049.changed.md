- A function-local name now counts as bound more than once by any binding the Python reference lists, not only by Jedi's definitions: a parameter, an import (`import os as X`), a match capture, a `type` statement or type parameter, and the rest, as well as a second class, a `def`, an assignment or `del`. So `resolve` answers `ambiguous` for a class that shares its name with a parameter or an import in its function, and `expand(…, "subclasses")` lists such a class under `handleless_subclasses` as `ambiguous_local` instead of as a stub. The not-found `detail` names every binding and its line (#1049).
