- Handles that pyeye's own edges emitted for a stub-only module (`expand(app, "imports")` giving `pkg.stubonly.S`) were rejected by `resolve` and `inspect`. They now round-trip (#933, #602).
- `callees` on a definition declared only in a stub, such as typeshed's `math.sqrt`, answered a measured `stubs: []` with `unresolved_call_sites: 0`, as if it called nothing. It now answers `unsupported` with `reason: "stub_declaration"` (#933).
