- Directory names that hold no project source now match in any case. `Build/`, `DIST/`, `Env/`, `.VENV/` and the like are skipped by the project scan and the file watcher, as `build/` and the rest already were, so on macOS and Windows such a tree is no longer scanned. This widens the exclusion. A directory holding `__init__.py` or `__init__.pyi` is still scanned whatever its name, and module, class and handle names stay case-sensitive. Scope classification uses the same name match (#1116).
