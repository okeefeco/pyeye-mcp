- The dogfooding setup script, the shell aliases it installs, the grep tracker and the MCP wrapper now run `scripts/dogfooding_metrics.py` through `uv run --frozen`. A bare `python` failed outside an activated venv (the script needs `click` and `pyeye`), and the aliases' `2>/dev/null || true` hid the failure, so grep tracking and auto-start silently did nothing. Setup now checks for `uv` instead of `python3`, and the commands in the dogfooding docs match. If you installed the aliases, re-run `scripts/setup_aliases.sh` to pick up the fix. (#879)
