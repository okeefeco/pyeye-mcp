- The path check now also refuses `/boot`, `/run/secrets`, `/var/run/secrets` and macOS root's home (`/var/root`). `/run`, `/var`, `/var/run` and `/private/var` are now refused as directories to scan.
- It also refuses credential stores directly below any user home (`/home/<user>`, `/Users/<user>`, `/root`, and the server's own home): `.ssh`, `.aws`, `.gnupg`, `.config/gcloud`, `.azure`, `.kube`, `.docker`, `.config/gh`, `.netrc`, `.pypirc`, `.pgpass`, `.git-credentials` and `.npmrc`. Directory scans skip these stores, while scanning `~`, `/home` or `/Users` still works. A project placed inside one of them is refused. A config entry that names one is skipped with a warning (#909).
