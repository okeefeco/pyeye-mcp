- If you ran those setup scripts, undo what they installed outside the repository, because it points at the deleted scripts (#1139):
  - `~/.local/bin/grep`, `egrep`, `fgrep` and `rg`: delete each one that contains the line `Auto-generated grep tracker wrapper for dogfooding metrics`. Until you do, that command fails, because the wrapper runs the deleted `scripts/grep_tracker.sh`.
  - `~/.claude/settings.json`: remove the hook entries whose command runs a script under `scripts/claude_hooks/`. The installer left a `settings.json.backup-<timestamp>` beside it.
  - `~/.claude/mcp_monitoring/` and its `aliases.sh` line in your shell profile, and the files under `~/.pyeye/metrics/`: delete them.
