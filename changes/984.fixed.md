- The `configure_packages` reference now says that a refused path passed in the call itself fails the call and saves nothing, while `rejected_paths` covers only entries already in the configuration. It also says that only plugin activation is limited to the startup project; the new paths take effect on any project you configure (#984).
- The pydantic tools page lists the un-annotated pydantic v1 attributes that are not fields (a lambda, a descriptor or private-attribute call, a name for a class or function), and says that a v1 nested `class Config:` is read. An executed example shows both (#984).
- The namespace packages guide no longer says namespace code is searched by default: without `scope_defaults`, a plugin tool searches only the main project. It also says that imports under `if TYPE_CHECKING:` and in `try`/`except` shims are followed by the `imports` edge, while imports inside a function are not. An executed example shows the rule (#984).
