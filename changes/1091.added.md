- `pyeye.docs_facts` can now run on a repository other than pyeye's own (#1091, RFC #1083 step 1).
  - **A `Setup`** (`pyeye.docs_facts.setup`) names what runs: the fact extractors, the doc registry, the prose rules, the generated reference pages and the changelog. `generate`, `check` and `changed` take it, and pyeye's own is the default, so its output is unchanged.
  - **Rules declare the facts they read.** A rule whose facts are absent, such as pyeye's edge rules on another codebase, is skipped and reported (`skipped rule <id>: needs <facts>`) instead of crashing. `honest-claims` needs none and always runs.
  - **The removed-name rules read `removed.json`** from the repository being checked, not from pyeye's checkout.
