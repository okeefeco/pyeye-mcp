- Path dependencies declared in a project's `pyproject.toml` are analysed as packages, read statically on every load and never saved (#1035):
  - **uv:** `[tool.uv.sources]` `path` entries and `[tool.uv.workspace]` members;
  - **Poetry:** `path` dependencies;
  - **PEP 621 / PEP 735:** `name @ file:...` references, with PDM's `${PROJECT_ROOT}` and Hatch's `{root:uri}` expanded.

  Each one is path-checked like a configured package, and `configure_packages`' `discovered` lists it with its source (`uv_source`, `uv_workspace`, `poetry_path` or `pep621_file_url`).
