- pyeye now requires watchdog 7.1.1 or newer, below 8 (`watchdog>=7.1.1,<8`), lifting the `<7` cap. 7.1.1 fixes both Windows problems behind the cap: change notifications held back while files keep changing (gorakhargosh/watchdog#1469), and a reader thread that could stop the server from exiting (gorakhargosh/watchdog#1470) (#1146).
- watchdog 7 reports a metadata-only change (touch, `os.utime`, chmod) as an "attrib" event instead of "modified". The file watcher now handles it, so touching a `.py` file still invalidates its caches (#1146).
