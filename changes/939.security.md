- A relative or absolute path that goes through a symlink and then `..` is now checked where it really leads. With `l_tmp` -> `/tmp`, the path `l_tmp/../etc` is `/etc` on disk, because the operating system follows the symlink first. The path check collapsed `..` first and saw `<project>/etc`, so `project_path="proj/l_tmp/../etc"`, or a `file` written that way, passed the check and the tool then read `/etc` (#939).
