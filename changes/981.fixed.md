- Internal dev tooling only (the repository's `scripts/`): `scripts/claude_hooks/setup_mcp_monitoring.sh` no longer wipes your Claude Code hooks. It replaced the whole `hooks` section of `~/.claude/settings.json`, or the whole file when `jq` wasn't installed, on every run. It now merges pyeye's hooks in with `python3`, and keeps your other settings and hooks. It replaces only pyeye's own entries, so re-running it is safe, and it leaves an unreadable settings file untouched. It still backs up the file first. It also no longer changes the file mode of a repository module, and on macOS it no longer fails at step 5 (the aliases), where BSD `sed -i` read its expression as a backup suffix. If an earlier run removed hooks of yours, they're in the `~/.claude/settings.json.backup-*` file that run made. (#981)
