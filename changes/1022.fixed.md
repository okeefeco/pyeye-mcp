- Two definitions of one name in one function (a `class Twin` in both branches of an `if`, or a class defined twice) share one handle, such as `pkg.mod.outer.Twin`, and pyeye used to answer for the first one. `resolve_at` on the second definition, or on a use after the branches, returned the first definition's location, and `resolve`, `inspect` and `expand` described one class for a name that names two. Now `resolve` on that name answers `ambiguous` with every definition as a candidate, as a bare name does. `resolve_at` answers with the definition at its position, at its own location, or `ambiguous` where it could be either. `inspect`, `expand` and `outline` answer not-found and say why. Module-level names are unchanged (#1022).
