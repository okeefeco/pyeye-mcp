- `expand(module, "imports")` marks an import that only an `if TYPE_CHECKING:` guard reaches: its stub carries `type_only: true`, and the key is absent for a runtime import. The guard can be `TYPE_CHECKING`, `typing.TYPE_CHECKING` or an alias of either, and an `else` branch counts as runtime. A target imported both ways isn't type-only. `trace(follow=["imports"])` puts the flag on the `imports` edge, `{from, to, kind, type_only: true}`, never on the node, because one module can be imported type-only by one module and at runtime by another (#1081).
