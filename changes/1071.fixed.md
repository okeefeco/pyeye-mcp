- Every stub handle the edges emit now resolves back, uniquely, to that stub (#1071).
  - A class nested in a function-local class (`pkg.m.f.Outer.Inner`) now has its handle in `superclasses`, `subclasses` and `members`. It used to be `no_handle`, and `subclasses` on it returned an empty list.
  - A function-local name that its function binds twice no longer produces a stub. That covers a parameter and a class with one name (`def g(X): class X`) and two `class` statements. Before, the stub carried a handle `resolve` answers as ambiguous. Now such a base is reported in `unresolved_superclasses` (reason `no_handle`), or as `ambiguous` with that candidate left out.
