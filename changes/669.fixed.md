- `expand(cls, "subclasses")` (and `trace(follow=["subclasses"])`) now finds subclasses in configured packages and namespace repos, not just the main project (#669). A subclass defined in a repo configured through `packages` or `namespaces` was missed, so the edge answered a confident `[]` while `expand(subclass, "superclasses")` named the base. The edge now searches the same project scope that `project` stubs come from: the main project plus configured packages and namespaces, but not standalone script directories. A relative namespace path in `.pyeye.json` (such as `../corp-tools`) is also normalised now. Before, files in that repo were named by their path instead of their module, so they could never be matched.
