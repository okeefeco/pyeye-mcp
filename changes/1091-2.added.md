- `scripts/docs_facts.py --root <repo>` now runs on any Python repository that declares a docs-facts config in `[tool.pyeye.docs_facts]` (in `pyproject.toml`) or under `"docs_facts"` in `.pyeye.json` (#1091, RFC #1083 step 1).
  - **Data only.** docs-facts never imports or runs the analysed repository's code. Facts come from built-in kinds: `literal` folds a module-level Python constant from the source, and `toml`/`json`/`yaml` read a dotted key path from a data file, YAML through `yaml.safe_load` only. Docs are inline tables. `rules` is `"all"` or a list. `paths` moves the records.
  - **Other kinds.** Further built-in kinds are configured with options through `[[tool.pyeye.docs_facts.extractors]]`.
  - **Refused:** a value that names code to import, an unknown key, kind or rule, and a file outside the repository.
  - pyeye's own repository selects its built-in setup with `preset = "pyeye"`. A repository with no config now gets "nothing to check" instead of pyeye's setup.
  - Verified on Scrapy 2.20.0 and Poetry 2.5.2, and on an inline-configured fixture checked in CI.
