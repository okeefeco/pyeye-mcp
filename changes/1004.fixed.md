- A package that is only stubs (`__init__.pyi` and no `__init__.py`) now has a handle. Before, its members resolved but the package itself didn't, so a handle `enclosing_scope` gave back was rejected by `resolve`. It is a namespace package, as Python and Jedi treat it.
- A namespace package's `members` now list what its portions' `__init__.pyi` declare, where before they were an empty list, and those names resolve. Where two portions declare the same name, the first portion's is used. Members declared in a stub carry `stub: true`; the package itself doesn't.
