- A project whose package under `src/` is a namespace package (no `__init__.py`), such as Poetry's `src/poetry`, was named `src.poetry.…`, and `resolve("poetry")` failed. Without a `.pyeye.json`, `src/` is now a source root when it holds the project's own package under its declared name (`[project].name` or `[tool.poetry].name`), as Poetry, Hatch, uv, PDM and setuptools expect by default. A `from`/`where` declared in `pyproject.toml` still takes precedence.
