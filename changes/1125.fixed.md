- A function or method that forwards `*args` / `**kwargs` now shows its declared signature in `inspect` and `outline`. Before, it showed the parameters of the call it forwards to: sometimes invalid Python (each name both positional-only and keyword-only, as for Scrapy's `LxmlLinkExtractor._extract_links`), sometimes a plausible signature it doesn't have. A rendered signature with a duplicated parameter name is never shown (#1125).
