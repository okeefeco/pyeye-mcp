- `expand(<class>, "subclasses")` reports the direct subclasses that no handle can name, instead of dropping them: a class defined in a function, in a file with no importable module path (such as `migrations/0001_initial.py`), or under a name the ASCII-only handle grammar rejects. `handleless_subclass_count` is always present on the edge and always complete; `handleless_subclasses` lists each one as `{name, file, line, reason}`, with `reason` one of `function_local`, `no_module_path` or `not_a_handle`, sorted by file then line. `max_stubs` caps that list separately from `stubs`, so a cut list shows as a count larger than the list. `trace` following `subclasses` carries `handleless_subclass_counts`, a `{handle: count}` map of the nodes that have any (#1006).
