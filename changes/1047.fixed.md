- On macOS and Windows, whose filesystems ignore case, a dotted name no longer matches a module file in another case: `pkg.Dyn` was taken for the module `pkg/dyn.py`, which Python can't import under that name, instead of the class `pkg.dyn.Dyn` it re-exports. A module name now matches its files only in exact case, as Python's import requires. Linux is unaffected (#1047).
