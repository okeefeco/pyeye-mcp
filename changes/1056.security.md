- The network-path filter on Jedi's reading of a project's `sys.path` changes is installed on its own, so a failure in another of pyeye's Jedi patches after an upgrade can no longer skip it. On POSIX, where no path is refused, `~user` paths are no longer expanded for the check. `SECURITY.md` now describes which repository-supplied paths are refused on Windows, including a `~/x` entry when the home directory is on a share (#1056).
