- pyeye configures docs-facts for itself in data, the same way any other repository does (#1107). Its doc registry is `docs/facts/docs.toml`, named by the config's `docs` key, which now also accepts the path of a TOML, JSON or YAML file. Its extractors are built-in `pyeye-*` kinds that run only on the repository whose `pyproject.toml` declares `name = "pyeye-mcp"`, and a new `pages` key names the built-in reference pages. The `preset` key is gone. The generated docs are unchanged.
