- Credential stores behind a symlinked home root (BSD's `/home` pointing at `/usr/home`) are refused, and directory walks skip them. Before, a walk through `/home/bob` could descend into `/usr/home/bob/.ssh`, which no home pattern named.
- When the server's `$HOME` isn't the user's home in the password database, that home's credential stores are covered too, including a store that is a symlink, matched where it points.
