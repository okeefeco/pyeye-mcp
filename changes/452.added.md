- Every edge now states how deterministic it is: `filesystem` (`submodules`), `ast` (`imported_by`, `re_exports`), `jedi_local` (`members`, `enclosing_scope`) or `goto` (`imports`, `callees`, `superclasses`, `subclasses`). The `expand` and `trace` descriptions, the python-explore skill and the edges reference page say what each tier guarantees across sessions. On a `goto` edge, an external target behind a try/except import shim may differ between processes (#419), and `subclasses` doesn't yet hold project scope stable for a base named through such a shim (#1057). A registry-driven test holds every edge to its tier (#452).
