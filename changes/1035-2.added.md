- Editable installs that use an import-hook `.pth` are now analysed too. These are setuptools with a flat layout, hatchling with `dev-mode-exact`, and pdm-backend with `editable-backend = "editables"` (#1035).
  - **Read, never run:** pyeye reads the hook's finder module as text. It takes setuptools' `MAPPING`/`NAMESPACES` literals, and the editables `map_module` calls.
  - **Limits:** only a module beside the `.pth` file that isn't a symlink and is within the size bound, and only plain string literals.
  - **Path checks:** every target is path-checked and counts toward the existing bounds, like any `.pth` path.
