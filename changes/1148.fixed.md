- The pyeye plugin installed from GitHub starts its MCP server again (#1148). Claude Code runs an installed plugin from a cache copy with no `.git`, and pyeye's version comes from git (setuptools-scm), so building its environment failed with `unable to detect version`. The setup hook exited 2 and the server never connected (`CONNECTION_CLOSED`). Where the plugin directory has no `.git`, the plugin now builds pyeye as the last release in `CHANGELOG.md` plus the cache directory's commit, e.g. `2.2.0+g11473fb4fd21`, which `pyeye://about` reports.
