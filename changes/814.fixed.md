- A package added with `configure_packages` under a directory whose name isn't a Python identifier (`.hidden/`, `my-dir/`) now resolves: its classes, functions, methods and attributes are found by `resolve`, `inspect`, `outline` and `expand`. Before, they were scanned but never resolved, and under an ordinary directory (`vendor/`) only top-level names resolved, by luck of a fallback (#814). A relative import inside a package under a dot-directory is still a known limit (#858).
