- `configure_packages` announces the tools it adds. When a call activates a framework plugin, the server sends one tools-changed event: `notifications/tools/list_changed` to clients on handshake-era protocols, and a `subscriptions/listen` event to clients on protocol 2026-07-28 or later. The server now advertises `tools.listChanged: true` on the handshake. A client that honours the event refreshes its tool list; one that doesn't can still call the new tools by name (#770).
