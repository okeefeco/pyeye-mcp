- `scripts/docs_facts.py generate` no longer depends on the order of earlier local runs (#1112). An intermediate run on a branch where a fact was briefly covered or absent moved it from the uncovered ledger's `baseline` to `new` for good, or left a permanent `removed.json` entry for a name that came back. `generate` now derives both records from their copies at the merge base with `origin/main` (`--base` names another branch). It keeps from the working tree only hand edits, hand-written entries and release-stamped `first_seen` values. Without git it works as before and says so.
