- Every caller-supplied path now goes through the input check in the form the tool finally uses: a relative path anchored on `project_path`, checked as spelled and with symlinks followed. Before, a relative path without `..`, `resolve`'s file forms (`f.py`, `f.py:42`), a plugin `scope="package:<path>"`, `configure_packages`' `namespaces` paths and `standalone_dirs`, and config-file namespace and standalone paths skipped the check. A refused tool argument is now an error, never a "not found". A refused config entry is skipped with a warning (#856).
