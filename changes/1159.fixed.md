- A signature whose source spans lines is now shown whole, on one line. A parameter annotation, default or return type written across several lines (Scrapy's `Request.__init__`, `headers: Mapping[str, Any] | Mapping[bytes, Any] | ...`) used to cut the `signature` off at the end of its first line: no closing parenthesis, and every later parameter and the return type missing. That affected `inspect`, `outline` and every edge's stubs. Such a signature is now re-rendered as Python, so a comment inside the annotation is dropped and a multi-line string default keeps its exact value (`'a\n  b'`). One that can't be re-rendered shows the declared signature, or none, never a cut-off one (#1159).
