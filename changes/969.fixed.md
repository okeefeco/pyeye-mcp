- Internal dev tooling only (the repository's `scripts/`, not the installed package): the `grep`, `egrep`, `fgrep` and `rg` wrappers that `scripts/setup_dogfooding.sh` installs in `~/.local/bin` no longer break those commands. `scripts/grep_tracker.sh` read the command from its own file name instead of its first argument, so every wrapped call failed with exit 127 and nothing was counted. It now takes the command from its argument and runs the first real binary on `PATH` that isn't a wrapper. The setup script no longer uses `grep` itself, so a re-run over the old, broken wrappers works. **If you ran the setup before this fix, re-run `bash scripts/setup_dogfooding.sh`, or delete `~/.local/bin/{grep,egrep,fgrep,rg}`.** (#969)
