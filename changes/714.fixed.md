- When the project root is reached through a symlink (for example any macOS temp directory), `resolve` no longer answers `found: true` with an invented `__main__.<name>` handle, and src-layout modules are no longer named `src.<package>…`. File-to-module matching now compares resolved paths while `location.file` keeps the caller's spelling (#603), and a handle's module part always comes from pyeye's own module mapper. A definition the mapper can't place is reported as not found (#714).
